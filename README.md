# AI-Powered ML, NLP & Deep Learning Data Science Assistant

## 📌 Project Overview

This project is an advanced AI-powered Machine Learning, NLP, Deep Learning, and Data Science Assistant designed to automate end-to-end data analysis workflows for text-based and structured datasets.

The application combines:

* Natural Language Processing (NLP)
* Traditional Machine Learning
* Deep Learning
* Ensemble Learning
* Stack-Based Ensemble Analysis
* AI-powered analytical assistance

The platform enables users to upload datasets, preprocess text, extract features, train multiple AI models, compare performance, generate visual analytics, and interact with an intelligent AI chatbot assistant.

This project was designed using PartyRock and extended conceptually into a scalable AI architecture for research, education, and business intelligence applications.

# 🧠 Ensemble Learning System

The application supports advanced ensemble learning techniques including:

* Voting Ensemble
* Bagging

* Blending Ensemble

Users can dynamically select multiple models for ensemble analysis.

* Base Models:

  * SVM

* Meta-Model:

  * Decision Tree

The system compares:

* Individual model performance
* Ensemble performance
* Stacked ensemble performance
